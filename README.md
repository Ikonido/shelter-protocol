# shelter-protocol
Бесплатная веб-игра для вечеринок в жанре социальной дедукции и выживания. Поддержка кастомных колод, нулевой бэкенд, работает оффлайн.

**Стек:** React + Vite + TypeScript, Tailwind CSS v4, Lucide, lz-string. Без сервера.

## Запуск
```bash
npm install
npm run dev      # разработка
npm test         # тесты логики
npm run build    # статическая сборка в dist/ (base './')
```
Деплой: GitHub Pages (`.github/workflows/pages.yml`), Cloudflare Pages или Vercel (build `npm run build`, output `dist`).

## Возможности
- Сценарии катастроф и паки карт (профессия, биология, здоровье, хобби, багаж, факт, действие).
- N игроков / K мест; режимы **Pass-and-Play** (шторка передачи устройства, тайное/открытое голосование, таймер дебатов, карты действий) и **Настольный** (генератор карточек: показать/скрыть, перекинуть, копировать, печать).
- Финал: сверка выживших с `requiredSkills` сценария + здоровье, ресурсы, стабильность.
- Свои паки: редактор, экспорт/импорт JSON (File System Access API с запасным вариантом), ссылки `#pack=...` (lz-string). Внешние данные санитизируются.
- **Онлайн-режим** («Новая игра → Онлайн»): хост создаёт комнату с 5-значным кодом / ссылкой `#join=КОД`, гости заходят из любой сети. Каждый играет на своём устройстве, чужие закрытые карты до клиентов не доходят. Отключившийся игрок возвращается по тому же коду (токен в `localStorage`), а хост может сделать за него автоход.
- Жёсткие лимиты на текст (`src/lib/limits.ts`): сценарий — название 60, описание 400, до 8 навыков и 6 угроз; карта — 240 символов, до 5 тегов; не более 12 сценариев и 60 карт в категории. Лимиты применяются в редакторе и при импорте.
- Паки и текущая локальная партия сохраняются в `localStorage`.

## Игра по локальной сети (без интернета)
Браузер не умеет принимать подключения, поэтому в LAN один из участников запускает крошечный сервер (раздаёт приложение и брокер соединений; игровые данные через него не идут):
```bash
npm install
npm run lan      # сборка + сервер на :8080  (PORT=9000 npm run lan — другой порт)
```
В консоли будет адрес вида `http://192.168.x.x:8080`. Хост открывает его, выбирает «Онлайн» → «Создать комнату»; остальные открывают тот же адрес (или ссылку-приглашение) и вводят код. Приложение само определяет LAN-сервер и не обращается к внешним сервисам. Сервер принимает только частные адреса (`--allow-public` отключает проверку). Подробности и ограничения — в [SECURITY.md](SECURITY.md).

## Как работает онлайн через интернет
Хост — это его браузер (авторитетное состояние игры). Связь — WebRTC через [PeerJS](https://peerjs.com); публичный брокер PeerJS используется только для рукопожатия, игровые данные идут напрямую. Ограничения: хост должен держать вкладку открытой; без TURN-сервера соединение не установится при «симметричных» NAT / некоторых корпоративных и мобильных сетях. Для надёжности можно задать при сборке свои сервисы:
```
VITE_PEER_HOST=peer.example.com VITE_PEER_PORT=443 VITE_PEER_PATH=/ VITE_PEER_SECURE=true
VITE_TURN_URL=turn:turn.example.com:3478 VITE_TURN_USER=... VITE_TURN_PASS=...
```
(TURN — например coturn). Безопасность и приватность: [SECURITY.md](SECURITY.md).

## Свои паки
Карта даёт навык, если её `tags` совпадают с одним из `requiredSkills` сценария (или навык встречается в тексте карты). Массовое добавление в редакторе: `Текст | + | тег1, тег2`.
