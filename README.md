# shelter-protocol
Бесплатная веб-игра для вечеринок в жанре социальной дедукции и выживания. Поддержка кастомных колод, нулевой бэкенд, работает оффлайн.

**Стек:** React + Vite + TypeScript, Tailwind CSS v4, Lucide, lz-string. Без сервера.

## Запуск
```bash
npm install
npm run dev      # разработка
npm test         # тесты логики
npm run build    # статическая сборка в dist/ (base './')
```
Деплой: GitHub Pages (`.github/workflows/pages.yml`), Cloudflare Pages или Vercel (build `npm run build`, output `dist`).

## Возможности
- Сценарии катастроф и паки карт (профессия, биология, здоровье, хобби, багаж, факт, действие).
- **Ход раунда:** игроки ходят по очереди: открывают карту (в самом первом вскрытии — «Биология»: пол и возраст, дальше по желанию) и в отведённое время (20–90 с, настраивается) объясняют, чем полезны убежищу; по таймеру ход переходит к следующему. Так проходит N вскрытий (по умолчанию 2), затем голосование. При N = 2 раундов не больше 3, чтобы хватило карт.
- **Встроенные паки:** «Классика: Конец света» (4 сценария), **«Средневековье»** (чума, осада замка, зима и орда; кузнецы, лекари, рыцари), **«Фэнтези: Эльдария»** (дракон, нежить, конец магии; расы эльфов, гномов, полуорков и др. со своими способностями) и **«18+ Без цензуры»** (корпоратив с зомби, новогодний кошмар, бункер для элиты; мат и чёрный юмор). У каждого пака свои карты, угрозы со сценами для хроники и тематические события раунда («Дракон кружит над долиной», «Кто выйдет за ворота?», «Нашлась нычка»). Пак 18+ включается после подтверждения возраста (запоминается на устройстве); в онлайн-комнате гости видят предупреждение 18+ до начала игры. Расы (карты «Биология») могут давать навыки наравне с профессиями.
- **Конструктор сценария** (меню → «Свой сценарий», без JSON и тегов вручную): пять шагов — основа (с шаблонами «Зомби», «Космический ковчег», «Восстание ИИ»), требуемые навыки, угрозы с тяжестью и «чем нейтрализуются», **способности карт** (любой профессии, хобби, багажу или факту, включая встроенные, можно задать, что она нейтрализует; свои карты) и проверка. Навыки выбираются чипами с числом карт, которые их дают; красный «0» и предупреждение на последнем шаге означают, что выиграть нельзя. Результат лежит в паке «Мои сценарии» (поле `tagOverrides` хранит переобученные способности, не меняя оригинальные карты), его можно экспортировать, дарить ссылкой и играть онлайн.
- **Сложность:** четыре пресета — Лёгкая / Обычная / Сложная / Кошмар. Они задают число угроз, пороги победы и гибели, силу штрафов, а на «Кошмаре» смертельную угрозу должны снимать двое выживших; заодно подставляют время речи и лимит партии (их можно изменить вручную).
- **Факторы угрозы:** у каждого сценария есть пул угроз (крысы и паразиты на корабле, течь, заражённая вода, мародёры, пожар…); в партию берётся 0–4 случайных. Каждую нужно нейтрализовать навыком, багажом или фактом кого-то из выживших (достаточно одного совпадения с тегами угрозы). Смертельная угроза без ответа = поражение, серьёзные и лёгкие снижают очки и мешают полной победе. Угрозы задаются в редакторе паков.
- **События раунда:** перед каждым раундом выпадает карта кризиса без повторов за партию — «Отказ вентиляции» (−1 место и +1 исключение), «Вспышка болезни» (больные открывают здоровье), «Утечка из архива» (все открывают ещё карту), «Радиомолчание» (речи вдвое короче), «Новая беда» (ещё одна угроза), «Подмога» (одна угроза снята), «Кто готов уйти добровольно?» (доброволец уменьшает квоту; закрытая квота — голосования нет) и вопросы для речи. На лёгкой чаще везёт, на «Кошмаре» чаще беды. По умолчанию выключены, включаются в настройках партии.
- **Хроника изоляции:** вместо сухого итога — таймлайн по сроку изоляции сценария: каждая угроза «разыгрывается» (кто и какой картой её снял — или почему провал), навыки, теснота, болезни; смертельная угроза обрывает историю. В конце эпилог из карт выживших (добровольцы запоминаются). Тексты сцен задаются в паке (поля «Хроника» у угрозы, `{who}` — кто справился), без них — шаблонные фразы. Работает без сервера и ИИ; в онлайн-партии у всех одинакова.
- **Воздержаться:** если воздержалось больше половины игроков, никто не уходит, а пропущенное исключение переносится в дополнительный раунд (всего не больше 8). Переполненный бункер в финале штрафуется.
- **Время партии:** лимит 15–120 минут, общий обратный отсчёт; по истечении речи пропускаются и карты открываются автоматически, голосование остаётся за игроками. Хост (или игрок в Pass-and-Play) может добавить 5 минут. В онлайн-игре время ведёт хост.
- N игроков / K мест; режимы **Pass-and-Play** (шторка передачи устройства, тайное/открытое голосование, карты действий) и **Настольный** (генератор карточек: показать/скрыть, перекинуть, копировать, печать).
- Финал: сверка выживших с `requiredSkills` сценария + здоровье, ресурсы, стабильность.
- Свои паки: редактор, экспорт/импорт JSON (File System Access API с запасным вариантом), ссылки `#pack=...` (lz-string). Внешние данные санитизируются.
- **Онлайн-режим** («Новая игра → Онлайн»): хост создаёт комнату с 5-значным кодом / ссылкой `#join=КОД`, гости заходят из любой сети. Каждый играет на своём устройстве, чужие закрытые карты до клиентов не доходят. Отключившийся игрок возвращается по тому же коду (токен в `localStorage`), а хост может сделать за него автоход.
- Жёсткие лимиты на текст (`src/lib/limits.ts`): сценарий — название 60, описание 400, до 8 навыков и 6 угроз; карта — 240 символов, до 5 тегов; не более 12 сценариев и 60 карт в категории. Лимиты применяются в редакторе и при импорте.
- Паки и текущая локальная партия сохраняются в `localStorage`.

## Телефонное приложение (PWA)
Игра устанавливается на телефон прямо из браузера — бесплатно, работает офлайн, обновляется само: меню → «Установить на телефон» (там же QR на сайт). Варианты раздачи через Google Play / APK и их стоимость — в [docs/MOBILE.md](docs/MOBILE.md).

## Вход по QR-коду
В лобби онлайн-комнаты хост видит **временный QR**: он содержит ссылку-приглашение с одноразовым «билетом» (действует 5 минут и обновляется сам; кнопка «Обновить QR» аннулирует старый сразу). Устаревший QR отклоняется. Опция «Вход только по QR» отключает вход по одному коду. В LAN-режиме QR всегда указывает на адрес устройства хоста в сети, а не на `localhost`.

## Обновление приложения
На главном экране внизу видны версия и дата сборки и кнопка **«Проверить обновления»**; при запуске и при возвращении в приложение (не чаще раза в 30 минут) версия проверяется тихо, и если вышла новая, сверху появляется баннер «Вышла новая версия» с кнопкой **«Обновить»**. Как это работает: сборка кладёт рядом с сайтом `version.json` (SHA коммита и время), приложение сравнивает его со своей версией; «Обновить» снимает service worker, чистит кеши приложения, принудительно перекачивает страницу и перезагружает. Партии и паки лежат в localStorage и сохраняются. Работает и в установленном PWA на Android, и в обычном браузере.

## Игра по локальной сети (без интернета)
Браузер не умеет принимать подключения, поэтому в LAN один из участников запускает крошечный сервер (раздаёт приложение и брокер соединений; игровые данные через него не идут):
```bash
npm install
npm run lan      # сборка + сервер на :8080  (PORT=9000 npm run lan — другой порт)
```
В консоли будет адрес вида `http://192.168.x.x:8080`. Хост открывает его, выбирает «Онлайн» → «Создать комнату»; остальные открывают тот же адрес (или ссылку-приглашение) и вводят код. Приложение само определяет LAN-сервер и не обращается к внешним сервисам. Сервер принимает только частные адреса (`--allow-public` отключает проверку). Подробности и ограничения — в [SECURITY.md](SECURITY.md).

## Как работает онлайн через интернет
Хост — это его браузер (авторитетное состояние игры). Связь — WebRTC через [PeerJS](https://peerjs.com); публичный брокер PeerJS используется только для рукопожатия, игровые данные идут напрямую. Ограничения: хост должен держать вкладку открытой; без TURN-сервера соединение не установится при «симметричных» NAT / некоторых корпоративных и мобильных сетях. Для надёжности можно задать при сборке свои сервисы:
```
VITE_PEER_HOST=peer.example.com VITE_PEER_PORT=443 VITE_PEER_PATH=/ VITE_PEER_SECURE=true
VITE_TURN_URL=turn:turn.example.com:3478 VITE_TURN_USER=... VITE_TURN_PASS=...
```
(TURN — например coturn). Безопасность и приватность: [SECURITY.md](SECURITY.md).

## Свои паки
Карта даёт навык, если её `tags` совпадают с одним из `requiredSkills` сценария (или навык встречается в тексте карты). Массовое добавление в редакторе: `Текст | + | тег1, тег2`.
