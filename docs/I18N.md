# Перевод интерфейса

Язык выбирается в **Настройках → Язык**: русский, украинский, английский, немецкий. По умолчанию — язык браузера (если он один из этих), иначе русский. Хранится на устройстве.

## Как устроено

- Ключ перевода — **русский исходный текст**. Если перевода нет, показывается русский, так что непереведённое не ломает экран.
- Русский — редакторский эталон для остальных языков. Исправления существующих формулировок задаются в `src/i18n/russian.ts`: прежний ключ → проверенный русский текст. `t()` показывает исправленный текст, а загрузчик создаёт для него соответствие в UK / EN / DE. Старые ключи в сохранениях и журнале остаются читаемыми; состояние партии не переписывается. Для новой строки используйте сразу проверенный русский текст.
- Обёртка: `t('Открыть карту')`, с переменными: `t('Раунд {n} из {total}', { n: 2, total: 5 })`.
- Переменные в переводе должны совпадать с ключом (проверяет `src/lib/i18n.test.ts`).
- Переводы лежат в `src/i18n/dict/<язык>/*.ts` (uk, en, de), по одному файлу на раздел. Структура частей одинаковая для всех языков: для каждого файла `dict/uk/x.ts` есть `dict/en/x.ts` и `dict/de/x.ts` с теми же ключами. Один и тот же ключ в нескольких частях одного языка переводится одинаково.
- Словарь грузится **по требованию**: русский использует исходные строки и небольшой модуль редакторских исправлений, остальные языки — отдельные чанки (`src/i18n/lang/<язык>.ts`), которые подключает `loadLang` из `src/i18n/registry.ts` до первого показа и при переключении языка. Русскоязычный игрок не скачивает иностранные словари. `src/i18n/index.ts` загружает все языки сразу — им пользуются тесты (через `src/test/setup.ts`), в приложение он не попадает: не импортируйте его из кода экранов.
- Склонение: `plural(n, { ru: [...], uk: [...], en: ['card', 'cards'], de: ['Karte', 'Karten'] })`. Для английского и немецкого — две формы (1 / остальные).
- Вызов `t()` делаем **в рендере или в обработчике**, а не в константах уровня модуля: иначе язык не переключится. Для таблиц подписей используем функции (`categoryLabel(c)`).
- Комментарии в коде остаются на русском.

## Стиль обращения

- Русский: «вы» со строчной буквы.
- Украинский: «ви».
- Английский: нейтральный.
- Немецкий: «du» (неформальное), во всех частях одинаково.
- Мат и грубость в наборе 18+ переведены по смыслу; окончательная редакция — отдельным решением владельца проекта.

## Статус и контроль качества

- **Русский** — исходный язык строк; **украинский, английский и немецкий** — отдельные словари для интерфейса, сетевых сообщений, карточек и встроенных сценариев.
- `src/lib/i18n.test.ts` проверяет совпадение ключей между частями всех трёх словарей, отсутствие конфликтующих повторов, непустые переводы и точное совпадение плейсхолдеров `{name}`, `{n}` и других.
- `src/i18n/russian.test.tsx` проверяет редакторские соответствия, сохранность переменных и старых записей журнала, совпадение ленивой и тестовой загрузки словарей и универсальную шторку передачи устройства на четырёх языках.
- Для встроенных паков тест проверяет наличие переводов каждого названия, описания, навыка, карты, сценария и угрозы на всех трёх языках. Новые карточки нужно добавлять во все словари.
- Переводы интерфейса и текстов из движка требуют редакторской проверки в контексте экрана, включая мобильную ширину: автоматические тесты не оценивают естественность формулировок и не гарантируют покрытие всех динамически сформированных строк.
- Пользовательский текст из собственных паков автоматически на другой язык **не переводится**. При отсутствии ключа интерфейс показывает исходную русскую строку.
- В режиме 18+ локализация ненормативной лексики проверяется отдельно: тексты не должны попадать в обычные наборы.

### Перед слиянием изменений перевода

1. Сначала проверить русский смысл по фактическим правилам и экрану, затем привести `uk`, `en`, `de` к нему. При редактуре прежнего ключа сохранить его соответствие в `russian.ts` и обновить перевод на всех трёх языках.
2. Проверить терминологию по глоссарию, обращение `du` в немецком и `ви` в украинском.
3. Не терять плейсхолдеры и условные обозначения (`{name}`, `{n}`, `QR`, `K`).
4. Запустить `npm test` и `npm run build`. Особенно проверить онлайн-комнату, выбор цели бонуса, голосование и передачу телефона.
