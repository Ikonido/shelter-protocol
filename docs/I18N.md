# Перевод интерфейса

Язык выбирается в **Настройках → Язык**: русский, украинский, английский, немецкий. По умолчанию — язык браузера (если он один из этих), иначе русский. Хранится на устройстве.

## Как устроено

- Ключ перевода — **русский исходный текст**. Если перевода нет, показывается русский, так что непереведённое не ломает экран.
- Обёртка: `t('Открыть карту')`, с переменными: `t('Раунд {n} из {total}', { n: 2, total: 5 })`.
- Переменные в переводе должны совпадать с ключом (проверяет `src/lib/i18n.test.ts`).
- Переводы лежат в `src/i18n/dict/<язык>/*.ts` (uk, en, de), по одному файлу на раздел. Структура частей одинаковая для всех языков: для каждого файла `dict/uk/x.ts` есть `dict/en/x.ts` и `dict/de/x.ts` с теми же ключами. Один и тот же ключ в нескольких частях одного языка переводится одинаково.
- Склонение: `plural(n, { ru: [...], uk: [...], en: ['card', 'cards'], de: ['Karte', 'Karten'] })`. Для английского и немецкого — две формы (1 / остальные).
- Вызов `t()` делаем **в рендере или в обработчике**, а не в константах уровня модуля: иначе язык не переключится. Для таблиц подписей используем функции (`categoryLabel(c)`).
- Комментарии в коде остаются на русском.

## Стиль обращения

- Украинский: «ви».
- Английский: нейтральный.
- Немецкий: «du» (неформальное), во всех частях одинаково.
- Мат и грубость в наборе 18+ переведены по смыслу; окончательная редакция — отдельным решением владельца проекта.

## Статус

- **Готово:** интерфейс всех экранов и компонентов (`src/screens`, `src/ui`), онлайн-сообщения, уведомления, тексты обновления и сохранения, картинка итога, настройки языка.
- **Не переведено:**
  - тексты движка: причины отказа действий (`lib/actions.ts`), записи лога (`lib/game.ts`), хроника (`lib/chronicle.ts`), заголовки и примечания итогов (`lib/evaluate.ts`), события (`lib/events.ts`), сложности (`lib/difficulty.ts`), навыки (`lib/vocab.ts`), конструктор (`lib/builder.ts`, `lib/generator.ts`);
  - игровой контент: карты, сценарии, угрозы, шаблоны (`src/data/*`) и названия паков;
  - пользовательский пак 18+ — нужна проверка, что мат не попадает в наборы без 18+.
- **Известные ограничения:**
  - проверки по тексту лога (`includes(' применяет ')` в `Game.tsx` и `Online.tsx`) сработают только на русском; при переводе логов заменить на структурный признак;
  - срок изоляции в конструкторе сохраняется русской строкой («3 года»), хроника разбирает только русские единицы;
  - имя по умолчанию «Игрок N» сохраняется в партии на языке момента старта.
